# 参照リンク (Independent)

ZoteroのPDF内の参考文献を検出し、ライブラリ内の文献・添付PDFへリンクする、Reference Linkerの独立版です。元のReference Linkerとは異なるプラグインIDを使います。

## インストールと更新

1. [配布ファイル](https://raw.githubusercontent.com/mcryo1108/sansho-link/main/dist/sansho-link-1.1.4.xpi)を保存します。
2. ZoteroのPlugins Managerで歯車 → Install Plugin From FileからXPIを選びます。
3. PDFを開き直し、参考文献のページで「参照 ↗」を押します。

1.0.2からの移行時は上記のファイルインストールが一度必要です。1.1.0以降の新しい版はPlugins ManagerのCheck for Updatesから確認できます。最初の起動時に旧版の更新停止設定を標準設定へ戻し、その後の利用者の更新設定は維持します。

同じPDFを二重に処理しないよう、元のReference Linkerは無効にして使ってください。

## 表示

- 黄色：ライブラリ内の文献と一致を確認できた参考文献。PDFボタンは添付PDFを開きます。
- グレー：参考文献は検出しましたが、一致するライブラリ文献を確定できません。マウスを重ねると理由を表示します。未登録であることを保証する表示ではありません。
- 無着色：参考文献範囲や表示位置を特定できていない可能性があります。

PDFにテキスト層が必要です。画像のみのPDFのOCRは行いません。画面に読み込まれたページへリンクを描画するため、参考文献ページまで移動して再スキャンしてください。

## 1.1.4の変更

- 補題・定理の英単語を限定する方式から、本体が記録した参照開始位置と単語・改行の境界を使う共通の補正へ変更。
- 図番号や別のラベル名、PDF内部の文字コードが画面の表記と違う場合にも、同じ原因による範囲の拡大を補正。
- 候補文字を囲んだ範囲が本体の元の範囲と一致し、実際に改行をまたぐ場合にだけ補正。数式の上下付き文字や位置を確定できないものは変更しません。
- 複数の番号形式と90度単位の回転を検証に追加。

補正は現在のページと、その後に読み込まれるページへ適用します。PDFファイル、注釈、青色、リンク先は維持します。異なる原因の誤検出や、対応する本体の内部処理がない場合は自動修正しません。

## 1.1.3の変更

- Zotero 10の自動内部リンクで、行末の「Lemma」と次の行頭の番号を一つの大きな四角形で囲み、本文まで青くなる場合の範囲補正を追加。
- 自動検出された数理用語のリンクについて、文字位置と開始位置が一意に確定し、元の範囲が明らかに広い場合だけ、文字の行ごとに範囲を絞り込みます。
- 青色、透明度、リンク先は維持します。保存済みの注釈とPDFファイルは変更しません。
- 補正は閲覧中だけ有効で、プラグイン停止時に元の範囲へ戻します。対応する本体の内部処理がない場合には補正を行いません。

Zotero 10.0.6の実際の文字・リンク解析データと、本体のクリック判定・色付け処理で検証しています。OS上の実画面での確認とは区別してください。

## 1.1.2の変更

- 更新・有効化の時点ですでに開いているPDFにも接続し、ボタンとリンク表示を復帰。
- ツールバーの重複を防ぎ、停止時に自分のボタンと表示だけを削除。
- 一時的な読み込み失敗や空の検出結果を固定せず、再試行を可能に。
- 停止後に待機中の処理が表示を復活させないように修正。

1.1.2の時点では薄青の自動リンク範囲は未変更でした。1.1.3から、上記の条件を満たす過大な範囲の補正を追加しています。

## 1.1.1の変更

- 参考文献一覧の最初の番号の左かっこが範囲から外れ、先頭1件だけ着色されない問題を修正。
- 番号形式・空白・本文中の同じ番号を含む、先頭項目の回帰テストを追加。

## 1.1.0の変更

- 本文や図説明の番号を参考文献番号と取り違える問題を修正。
- 見出しのない番号付き参考文献一覧でも、一覧の先頭から表示範囲を絞り込み。
- グレー表示に未一致理由を追加。
- 文献追加・変更時と手動再スキャン時にライブラリの索引を更新。
- HTTPSの更新情報とSHA-256付き配布ファイルに対応。

Zotero 10.0.6の更新判定コードとPDFテキストを使った回帰検証を実施しています。全てのPDF形式やZoteroの全バージョンでの動作を保証するものではありません。

## ビルド

Python 3で `python3 build.py` を実行します。追加ライブラリは不要です。`src/`からXPIと`updates.json`を生成します。新しい版を配布するときは`src/manifest.json`のversionを変更し、生成したdistファイルとupdates.jsonを同じコミットで公開してください。公開済みの版番号のXPIを別内容へ置き換えないでください。

Node.jsがあれば `node tests/smoke.mjs` で先頭番号の回帰テスト、`node tests/lifecycle.mjs` で開いているPDFへの接続・停止・再試行の回帰テストを実行できます。`node tests/native-bounds.mjs` では、内部リンク範囲の補正・リンク先の維持・停止時の復元を確認できます。合成テキストと模擬DOMを使うテストで、Zotero実画面の検証ではありません。
